🔄 Rolling Release Debian sid 🌐 Trilingüe

GNU/Linux con cerebro STEM + oficio ARTS

TobiXu (托比·许) es una familia de distribuciones GNU/Linux diseñada para científicos, ingenieros, artistas y creadores. Combina un cerebro STEM completo con un oficio ARTS profesional, todo envuelto en una identidad visual trilingüe que honra el español hablado en México, el chino mandarín y el inglés.

🔄 Rolling Release: siempre al día

TobiXu está basada en Debian sid, la rama unstable de Debian. Recibes las últimas versiones de todo el software sin esperar a un release mayor. Una vez instalada, tu sistema nunca queda obsoleto: una actualización continua te mantiene en la vanguardia.

Ventajas: software fresco, kernel reciente, drivers nuevos, librerías actualizadas.
Consideración: requiere usuarios dispuestos a convivir con la vanguardia y hacer mantenimiento ocasional.

¿Qué incluye?

Instalación (variantes base)

  1. Descarga la ISO desde Archive.org
  2. Grábala en USB con dd o Balena Etcher
  3. Arranca en modo UEFI (desactiva Secure Boot si es necesario)
  4. Pruébala en modo live (sin instalar)
  5. Instala con Calamares (puerta Instalar TobiXu en el escritorio)
  6. Tras el primer arranque, instala la paquetería tobixu:
    sudo apt update && sudo apt install tobixu-stem tobixu-arts
