Distribución Linux con cerebro STEM + oficio ARTS

Tobi Xu (托比·许) es una distribución Linux diseñada para científicos, ingenieros, artistas y creadores. Combina un cerebro STEM completo con un oficio ARTS profesional, todo envuelto en una identidad visual trilingüe que honra el español hablado en México, el chino mandarín y el inglés.

🔄 Rolling Release: siempre al día

Tobi Xu está basada en Debian sid, la rama unstable de Debian. Esto significa que recibes las últimas versiones de todo el software sin esperar a un "release" mayor. Una vez instalada, tu sistema nunca queda obsoleto: una actualización continua te mantiene en la vanguardia.

Ventajas: software fresco, kernel reciente, drivers nuevos, librerías actualizadas.
Consideración: requiere usuarios dispuestos a convivir con la vanguardia y hacer mantenimiento ocasional.

¿Qué incluye?

🧪 Cerebro STEM

  • texstudio — editor LaTeX profesional
  • frescobaldi — editor de partituras LilyPond
  • libreoffice — suite ofimática completa
  • qgis — sistemas de información geográfica
  • octave — cálculo numérico (compatible MATLAB)
  • gnugo, gnuchess — juegos estratégicos
  • 12 sgt-puzzles — rompecabezas lógicos

🎨 Oficio ARTS

  • kdenlive — edición de video profesional
  • obs-studio — streaming y grabación
  • vlc — reproductor multimedia
  • handbrake — conversión de video
  • krita — pintura digital (Recommends)
  • ardour — estación de audio digital (Recommends)
  • musescore — notación musical (Recommends)
  • 🎭 Identidad visual trilingüe: velo (Plymouth) + puerta (SDDM) + splash, en español, 中文 e inglés

Instalación

  1. Descarga la ISO desde Archive.org
  2. Grábala en USB con dd o Balena Etcher
  3. Arranca en modo UEFI (desactiva Secure Boot si es necesario)
  4. Pruébala en modo live (sin instalar)
  5. Instala con Calamares (puerta Instalar Tobi Xu en el escritorio)

Paquetes en Recommends (instalación post-arranque)

Algunos paquetes que estaban en transición ABI al momento del build se instalan después del primer arranque, ya con sid vivo:

  • sudo apt install julia r-base octave qgis — transiciones LLVM/R
  • sudo apt install krita ardour musescore lmms — transiciones ABI multimedia
  • sudo apt install texlive-full sagemath root-system paraview blender — complementos opcionales
