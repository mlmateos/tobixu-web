TobiXu

"The river does not rush, guardian: it finds its channel."
🔄 Rolling Release Debian sid 🌐 Trilingual

GNU/Linux with a STEM brain + ARTS craft

TobiXu (托比·许) is a family of GNU/Linux distributions designed for scientists, engineers, artists and creators. It combines a complete STEM brain with a professional ARTS craft, wrapped in a trilingual visual identity that honors Mexican Spanish, Mandarin Chinese and English.

🔄 Rolling Release: always up to date

TobiXu is based on Debian sid, the unstable branch of Debian. You receive the latest versions of all software without waiting for a major release. Once installed, your system never becomes obsolete: continuous updates keep you at the cutting edge.

Advantages: fresh software, recent kernel, new drivers, updated libraries.
Consideration: requires users willing to live on the cutting edge and perform occasional maintenance.

What does it include?

🧪 STEM brain

  • texstudio — professional LaTeX editor
  • frescobaldi — LilyPond score editor
  • libreoffice — complete office suite
  • qgis — geographic information systems
  • octave — numerical computing (MATLAB compatible)

  • 12 sgt-puzzles — logic puzzles

🎨 ARTS craft

  • kdenlive — professional video editing
  • obs-studio — streaming and recording

  • handbrake — video conversion
  • krita — digital painting (Recommends)
  • ardour — digital audio workstation (Recommends)

The STEM and ARTS package sets grow continuously: each bake of the river adds new tools to the brain and the craft.

Installation (base variants)

  1. Download the ISO from Archive.org
  2. Burn it to USB with dd or Balena Etcher
  3. Boot in UEFI mode (disable Secure Boot if needed)
  4. Try it in live mode (without installing)
  5. Install with Calamares (the Install TobiXu door on the desktop)
  6. After first boot, install the TobiXu packages:
    sudo apt update && sudo apt install tobixu-stem tobixu-arts
