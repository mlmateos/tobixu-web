GNU/Linux Distro with STEM brain + ARTS craft

Tobi Xu (托比·许) is a GNU/Linux distro designed for scientists, engineers, artists, and creators. It combines a complete STEM brain with a professional ARTS craft, all wrapped in a trilingual visual identity that honors Mexican Spanish, Mandarin Chinese, and English.

🔄 Rolling Release: always up to date

Tobi Xu is based on Debian sid, the unstable branch of Debian. This means you get the latest versions of all software without waiting for a major release. Once installed, your system never becomes outdated: a continuous update stream keeps you at the cutting edge.

Benefits: fresh software, recent kernels, new drivers, updated libraries.
Consideration: requires users comfortable with the cutting edge and occasional maintenance.

Installation

  1. Download the ISO from Archive.org
  2. Burn to USB with dd or Balena Etcher
  3. Boot in UEFI mode (disable Secure Boot if needed)
  4. Try in live mode (without installing)
  5. Install with Calamares (Install Tobi Xu door on desktop)

Recommends packages (post-boot installation)

Some packages that were in ABI transition at build time are installed after first boot, with live sid:

  • sudo apt install julia r-base octave qgis — LLVM/R transitions
  • sudo apt install krita ardour musescore lmms — multimedia ABI transitions
  • sudo apt install texlive-full sagemath root-system paraview blender — optional complements
