GNU/Linux 发行版：STEM 大脑 + ARTS 工艺

Tobi Xu（托比·许）是为科学家、工程师、艺术家和创作者设计的 GNU/Linux 发行版。它将完整的 STEM 大脑与专业的 ARTS 工艺相结合，所有这些都包裹在尊重墨西哥西班牙语、中文和英语的三语视觉身份中。

🔄 滚动发行：始终保持最新

Tobi Xu 基于 Debian sid，即 Debian 的不稳定分支。这意味着您无需等待主要版本发布即可获得所有软件的最新版本。安装后，您的系统永远不会过时：持续更新流让您始终处于最前沿。

优势：新鲜的软件、最近的内核、新的驱动程序、更新的库。
考虑因素：需要用户适应前沿技术并偶尔进行维护。

安装

  1. 从 Archive.org 下载 ISO
  2. 使用 dd 或 Balena Etcher 刻录到 USB
  3. 以 UEFI 模式启动（如需要则禁用安全启动）
  4. 在实时模式下试用（不安装）
  5. 使用 Calamares 安装（桌面上的"安装 Tobi Xu"门）

推荐软件包（启动后安装）

构建时处于 ABI 转换阶段的一些软件包在首次启动后使用实时 sid 安装：

  • sudo apt install julia r-base octave qgis — LLVM/R 转换
  • sudo apt install krita ardour musescore lmms — 多媒体 ABI 转换
  • sudo apt install texlive-full sagemath root-system paraview blender — 可选补充
