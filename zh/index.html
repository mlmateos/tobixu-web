拥有 STEM 大脑 + ARTS 手艺的 GNU/Linux

TobiXu（托比·许）是为科学家、工程师、艺术家和创作者设计的 GNU/Linux 发行版家族。它将完整的 STEM 大脑与专业的 ARTS 手艺结合在一起，并以尊重墨西哥西班牙语、中文普通话和英语的三语视觉身份呈现。

🔄 滚动发布：始终保持最新

TobiXu 基于 Debian sid，即 Debian 的 unstable 分支。您无需等待重大发布即可获得所有软件的最新版本。一旦安装，您的系统永远不会过时：持续更新让您始终走在前沿。

优势： 最新软件、较新内核、新驱动、更新的库。
考量： 需要愿意与前沿共存并偶尔进行维护的用户。

安装（基础变体）

  1. 从 Archive.org 下载 ISO
  2. 使用 dd 或 Balena Etcher 刻录到 USB
  3. 以 UEFI 模式启动（如有必要，禁用 Secure Boot）
  4. 以 live 模式试用（不安装）
  5. 使用 Calamares 安装（桌面上的 Instalar TobiXu 门）
  6. 首次启动后，安装 TobiXu 软件包：
    sudo apt update && sudo apt install tobixu-stem tobixu-arts
